# 2026-08-14 — Attach TestFlight 1.0.14 to App Store version 1.0

## Summary

Distribution and TestFlight were looking at different records.  App Store
version **1.0** (created 2026-08-04) still had the rejected **1.0.7** build
attached, so the Distribution tab said Invalid Binary.  TestFlight already
had **1.0.14** (`202608141034`, uploaded 2026-08-14, `VALID`, in internal
beta).  Uploading a TestFlight IPA does not replace the App Store
attachment.

Attached `1.0.14` to version `1.0` via the App Store Connect API.

## Files changed

- `docs/EFFORT-LOG.md` — closeout row
- `STATUS.md` — live snapshot
- this rollout note

No app or iOS code.  ASC write only.

## Follow-ups

- Version is **not** submitted for review.  Owner can Submit for Review on
  version 1.0 in App Store Connect, or ask an agent to submit via the API.
- The Distribution header will still say **1.0**.  The Build row should now
  show **202608141034** (the 1.0.14 binary), not 1.0.7.
